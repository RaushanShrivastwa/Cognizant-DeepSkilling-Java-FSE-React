\# Lab 1: Git Setup, Configuration, and Basic Workflow



**Definitions \& Concepts**

* **git init**: Initializes a new, empty Git repository in the target directory by creating a hidden `.git` folder.
* **git status**: Displays the state of the working directory and staging area, showing tracked, untracked, and modified files.
* **git add**: Adds changes from the working directory to the staging area (index) to prepare them for commit.
* **git commit**: Saves a snapshot of staged changes into the local repository database.
* **git push**: Uploads local branch commits to a remote repository.
* **git pull**: Fetches content from a remote repository and immediately merges it into the current local branch.
* **git config**: Configures Git settings such as username, email address, and default text editor.
