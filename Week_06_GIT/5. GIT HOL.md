\# Lab 5: Repository Cleanup and Push to Remote Git



\## Concepts \& Definitions

* \*\*Repository Cleanup\*\*: Removing unused local/remote branches and clearing temporary files to maintain a clean workspace before synchronization.
* \*\*Remote Synchronization\*\*: Pulling down remote commits and pushing local commits to sync local development with the central remote repository.



\---



\## Exercise Steps



\### Step 1: Cleanup Local Workspace

\# Verify master working tree is clean

git status



\# List all available branches to ensure unused branches are deleted

git branch -a



\### Step 2: Sync and Push to Remote Repository

\# Pull latest changes from remote Git repository to ensure master is up to date

git pull origin master



\# Push pending local commits from previous lab exercises to remote repository

git push origin master



\# Verify status reflects local repository is up to date with remote origin

git status
