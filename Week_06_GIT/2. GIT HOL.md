\# Lab 2: Git Ignore Configuration



\## **Concepts \& Definitions**

* \*\*`.gitignore`\*\*: A text file that tells Git which untracked files or directories to intentionally ignore and omit from version tracking\[cite: 2].
* \*\*Wildcard Matching (`\*.extension`)\*\*: A pattern like `\*.log` matches all files ending with `.log` in any folder inside the repository\[cite: 2].
* \*\*Directory Exclusion (`folder/`)\*\*: A trailing slash indicates that the target is a directory, telling Git to ignore the folder and all nested contents inside it\[cite: 2].



\---



\## Exercise Steps



\### Step 1: Create Log File and Folder

\# Create a .log file in the root working directory

echo "Error log entry" > app.log



\# Create a log directory with nested log files

mkdir log

echo "Debug log entry" > log/debug.log



\# Check repository status (files appear as untracked)

git status



\### Step 2: Configure `.gitignore` File

\# Append pattern to ignore all .log extension files

echo "\*.log" >> .gitignore



\# Append pattern to ignore the entire log directory

echo "log/" >> .gitignore



\# Verify .gitignore content

cat .gitignore



\### Step 3: Verify Tracking Exclusion

\# Check repository status (app.log and log/ directory should now be ignored)

git status



\# Stage and commit only the .gitignore file

git add .gitignore

git commit -m "Add .gitignore to exclude .log files and log directory"



\# Verify working directory is clean

git status
