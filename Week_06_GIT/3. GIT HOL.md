\# Lab 3: Branching, Merging, and Visual Diffing



\## **Concepts \& Definitions**

* \*\*`Branching`\*\*: Creating an independent line of development to work on features without affecting the main execution trunk\[cite: 3].
* \*\*`Merging`\*\*: Combining changes from one branch into another\[cite: 3].
* \*\*`Trunk/Master`\*\*: The main line of development in a repository\[cite: 3].
* \*\*`git diff`\*\*: Command used to display line-by-line differences between commits, branches, or working directory files\[cite: 3].
* \*\*`P4Merge`\*\*: A graphical visual merge and diff tool used to compare differences and resolve conflicts\[cite: 3].



\---



\## **Exercise Steps**



\### Step 1: Create and Work on a Branch

\# Create a new branch named GitNewBranch

git branch GitNewBranch



\# List all local and remote branches (\* indicates active branch)

git branch -a



\# Switch working workspace to GitNewBranch

git checkout GitNewBranch



\# Create a new file and commit changes within GitNewBranch

echo "Feature content" > feature.txt

git add feature.txt

git commit -m "Add feature.txt in GitNewBranch"



\# Verify branch status

git status



\### Step 2: Compare and Merge Branches

\# Switch back to the master branch

git checkout master



\# Command line list of differences between master and GitNewBranch

git diff master GitNewBranch



\# Launch P4Merge graphical diff tool to visually compare differences

git difftool -t p4merge master GitNewBranch



\# Merge GitNewBranch changes into master branch

git merge GitNewBranch



\# View graphical log history of commits and branch merges

git log --oneline --graph --decorate



\# Delete merged branch and verify status

git branch -d GitNewBranch

git status
