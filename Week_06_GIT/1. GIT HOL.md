# Lab 1: Git Setup, Configuration, and Basic Workflow

Definitions & Concepts
git init: Initializes a new, empty Git repository in the target directory by creating a hidden `.git` folder.
git status: Displays the state of the working directory and staging area, showing tracked, untracked, and modified files.
git add: Adds changes from the working directory to the staging area (index) to prepare them for commit.
git commit: Saves a snapshot of staged changes into the local repository database.
git push: Uploads local branch commits to a remote repository.
git pull: Fetches content from a remote repository and immediately merges it into the current local branch.
git config: Configures Git settings such as username, email address, and default text editor.

Exercise Steps

### Step 1: Setup Machine Configuration
```bash
# Verify Git installation and check the current version
git version

# Configure global user profile (Use personal credentials, NOT organizational ones)
git config --global user.name "YourUsername"
git config --global user.email "your_email@example.com"

# Check if global configurations are correctly set
git config --global --list

```

### Step 2: Integrate Notepad++ as Default Editor
```bash
# Verify if notepad++ command is recognized in Git Bash
notepad++

# Create a bash profile alias for Notepad++
echo "alias npp='notepad++.exe -multiInst -nosession'" >> ~/.bash_profile

# Configure Notepad++ as the global default Git text editor
git config --global core.editor "notepad++.exe -multiInst -nosession"

# Verify default editor setup (-e option opens the git config file in the default editor)
git config --global -e
```


### Step 3: Add File to Source Code Repository
```bash
# Initialize a new Git repository named GitDemo
git init GitDemo
cd GitDemo

# View hidden files including the initialized .git folder
ls -al

# Create a file named welcome.txt with content
echo "Welcome to the version control" >> welcome.txt

# Verify file creation and inspect content
ls -al
cat welcome.txt

# Inspect repository status (shows welcome.txt as untracked)
git status

# Stage welcome.txt for commit
git add welcome.txt

# Commit staged changes (opens Notepad++ for multi-line commit message)
git commit

# Verify clean working tree state
git status

```

### Step 4: Synchronize with Remote GitHub Repository
```bash
# Link local repository to your remote GitHub repository
git remote add origin [https://github.com/YourUsername/GitDemo.git](https://github.com/YourUsername/GitDemo.git)

# Pull remote branch content into master
git pull origin master --allow-unrelated-histories

# Push committed changes to remote repository
git push -u origin master
